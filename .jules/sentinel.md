## 2024-05-24 - SQL Injection in Management Commands
**Vulnerability:** Found raw SQL injection vulnerabilities in `openedx/core/djangoapps/user_api/management/commands/email_opt_in_list.py` and `openedx/core/djangoapps/user_api/management/commands/bulk_user_org_email_optout.py` where unescaped string formatting was used with `.format()` to construct SQL queries, including `IN` clauses for lists and `VALUES` combinations.
**Learning:** Even internal management commands and background jobs must use parameterized queries. Using `.format()` for lists inside a query bypasses normal safety mechanics, creating potential SQLi if arguments (like `org_aliases` or `courses`) originate from untrusted input down the line.
**Prevention:** When using `cursor.execute()`, never use `str.format()` or f-strings for dynamic data. Always use `%s` parameterization (e.g., `",".join(["%s"] * len(items))` for `IN` lists) and pass the values as a flat tuple or list as the second argument to `execute()`.
