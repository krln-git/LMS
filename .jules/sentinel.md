## 2024-05-24 - [CRITICAL] Fixed DOM-based XSS in enrollment error messaging
**Vulnerability:** Found a DOM-based Cross-Site Scripting (XSS) vulnerability in `lms/static/js/student_account/enrollment.js`. The `showMessage` function extracted an error message from an API response (`message.detail`) and directly interpolated it into an HTML template literal assigned to `messageDiv.innerHTML`. This allowed any unescaped HTML/JS returned by the API to be executed by the browser.
**Learning:** Even internal API error messages can be vectors for XSS if they reflect user input (e.g., an invalid course ID) and are rendered unsafely on the client side. The pattern of assigning template literals with dynamic variables to `.innerHTML` is highly dangerous.
**Prevention:** Always use `.textContent` (or `innerText`) when dynamically inserting untrusted text into the DOM. If HTML formatting is required, construct elements individually using `document.createElement` or use a robust client-side HTML sanitizer (like DOMPurify) before assignment to `.innerHTML`.
