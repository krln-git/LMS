## 2024-10-08 - Fix command injection in clean_xml.py
**Vulnerability:** A command injection vulnerability existed in `lms/djangoapps/courseware/management/commands/clean_xml.py` because `os.system` was used with string interpolation (`f'diff -r {course_dir} {export_dir}'`) without properly escaping or validating the variables, exposing the system to potential shell injection via the directory paths.
**Learning:** `os.system` runs a command through a shell, which can be vulnerable to command injection if arguments aren't sanitized. String interpolation directly inside a shell execution command is inherently risky. Also `path.py` objects passed to `subprocess.run` need explicit casting to `str`.
**Prevention:** Use `subprocess.run` and construct arguments as a list (e.g. `['diff', '-r', str(course_dir), str(export_dir)]`) so that inputs are passed properly as distinct arguments without shell interpretation. Set `check=False` to preserve the previous behavior. Never use `os.system` with unsanitized user inputs.
