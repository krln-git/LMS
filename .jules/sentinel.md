## 2024-05-15 - [CRITICAL] Fix SQL injection in management commands raw SQL bulk inserts
**Vulnerability:** Management commands utilizing raw SQL queries (like `bulk_user_org_email_optout.py`) constructed via Python string formatting (e.g., `query_values.append('({}, "{}")'.format(val1, val2))`) instead of parameterized queries.
**Learning:** Raw SQL bulk inserts using python string formats are an easy target for SQL injection attacks, especially if the data originates from external files such as CSVs without prior sanitization. Even internal management commands should never trust user input. When constructing dynamic `IN` clauses or bulk inserts in raw SQL in Django, `','.join(['%s'] * len(values))` should be used.
**Prevention:** Always use parameterized queries `(%s)` to construct a query string and pass parameters to `cursor.execute(query, params)` as a flattened list of variables. Never use string interpolation or concatenation when forming raw SQL queries containing variables.
