## 2024-05-18 - Prevent SQL Injection in Django Raw Bulk Inserts
**Vulnerability:** A raw SQL bulk insert in `bulk_user_org_email_optout.py` used `.format()` to directly interpolate variables into the `VALUES` clause (e.g., `query_values.append('({},"{}","email-optin","False",NOW(),NOW())'.format(user_id, org))`), which is vulnerable to SQL injection if `org` is maliciously crafted in the CSV input.
**Learning:** This existed because the command bypassed the Django ORM to optimize bulk updates/inserts with `ON DUPLICATE KEY UPDATE`. When constructing raw SQL strings manually for efficiency, the risk of string formatting-based SQL injection is high.
**Prevention:** When performing raw SQL bulk inserts in Django, construct a single query string using `%s` placeholders (e.g., `(%s, %s, "email-optin", "False", NOW(), NOW())`) and pass a single, flattened list of all parameters to `cursor.execute(query, params)`. Do not use `.format()` or f-strings for SQL query data interpolation.
