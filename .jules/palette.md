## 2024-05-01 - Improve custom toggle UI accessibility
**Learning:** When building custom toggle interactions (like popovers/modals) with display logic, it is critical to use semantic `<button>` tags instead of `<div>`s for all interactive elements (like close or copy buttons). Additionally, the toggle button needs `aria-expanded` and `aria-controls` linked to the target container, and focus must be programmatically managed (returning focus to the toggle on close, and moving focus to the close button on open) to ensure full screen reader and keyboard accessibility.
**Action:** Always refactor interactive `<div>`s to native `<button>`s, explicitly set dynamic `aria-expanded` attributes, hide decorative icons with `aria-hidden="true"`, and implement proper focus management when building or updating custom UI toggles.
