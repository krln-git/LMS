## 2024-04-09 - Refactor interactive div elements to native buttons
**Learning:** In Open edX templates, some interactive elements like "close" or "copy" buttons are incorrectly implemented as styled `<div>` tags (e.g., `<div class="btn-link">`). This pattern breaks keyboard accessibility as `<div>` elements don't natively support focus or `Enter`/`Space` activation. Additionally, FontAwesome icons should not be self-closing (e.g., `<span />`), as they may cause rendering issues or screen reader confusion if not paired with `aria-hidden="true"`.
**Action:** Always refactor interactive `<div>` elements that function as buttons into semantic `<button type="button">` elements to ensure proper keyboard navigability and screen reader support out of the box. Ensure decorative icons use properly closed tags (e.g., `<span class="icon" aria-hidden="true"></span>`).
