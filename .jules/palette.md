## 2024-05-15 - ARIA Labels in Underscore Templates
**Learning:** When assigning localized string expressions (like Backbone `<%- gettext("Text") %>`) to HTML attributes (such as `aria-label`) in `.underscore` templates, you must enclose the expression in explicit HTML quotes (e.g., `aria-label="<%- gettext("Text") %>"`) to prevent parsing errors and accessibility issues if the evaluated string contains spaces. Furthermore, when using Python scripts to inject these, do not backslash-escape the single quotes inside the JS function call to avoid SyntaxErrors during compilation.
**Action:** Always test the template rendering after adding ARIA labels with translations to ensure they parse correctly, and use triple quotes in Python replacement scripts to avoid escaping issues.
