## 2024-05-24 - Add ARIA labels to icon-only delete buttons in CMS Backbone templates
**Learning:** Found multiple instances of icon-only delete buttons in CMS Backbone templates (`.underscore` files) that rely solely on `title` attributes for accessibility. While `title` can act as a fallback, explicitly defining `aria-label` is more robust for screen readers. Since these are Backbone/Underscore templates, we need to use `<%- gettext("...") %>` for translated strings instead of Django/Mako `${_("...")}` syntax. Additionally, the inner FontAwesome icon (`<span class="icon fa fa-trash-o">`) correctly uses `aria-hidden="true"`.
**Action:** Added `aria-label="<%- gettext('Delete') %>"` alongside the existing `title` attribute to icon-only delete buttons in `partition-group-details.underscore`, `show-textbook.underscore`, `certificate-details.underscore`, and `group-configuration-details.underscore` to improve screen reader accessibility without changing the visual design.
