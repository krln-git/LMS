## 2024-05-24 - Screen Reader Text Not Translated to aria-label on Close Modal Buttons
**Learning:** In several templates (e.g., `dashboard.html`, `forgot_password_modal.html`), the `close-modal` buttons lack `aria-label` attributes. While they contain a `.sr` (screen reader) text span for accessibility, assigning an explicit `aria-label` directly on the `<button>` element is a more robust UX pattern for screen readers. Using Mako expressions for HTML attributes requires them to be correctly enclosed in quotes.
**Action:** When encountering icon-only buttons or buttons that rely on `.sr` text spans, always explicitly add the translated `aria-label` attribute (e.g., `aria-label="${_('Close')}"`) to the button itself for better accessibility support across different screen readers.
