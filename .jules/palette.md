## 2024-05-20 - Accessible Toggles and Semantic Buttons
**Learning:** When fixing custom UI toggles (like social sharing dialogs), changing styled `<div>` elements with `.btn-link` to semantic `<button>` elements is only half the battle. Keyboard accessibility also requires active focus management: returning focus to the original toggle button when the container is hidden, and shifting focus to the first interactive element (like the close button) when opened. Additionally, self-closing tags for non-void elements like `<span>` in Mako templates should be avoided.
**Action:** Always verify keyboard navigation for custom toggles. Use native `<button>` tags with `.btn-link` rather than custom inline CSS to reset styles. Ensure dynamic translatable strings in Mako templates like `${_('Close')}` are enclosed in standard HTML quotes.
