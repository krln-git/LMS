## 2024-05-22 - Replacing `len(queryset)` and `queryset.count() == 0` with `queryset.exists()`
**Learning:** Found multiple instances where the codebase was using `len(QuerySet) != 0` or `QuerySet.count() == 0` for simple existence checks. `len()` causes all matching rows to be fetched into application memory, which can be disastrous for large querysets. `count()` evaluates a full `COUNT(*)` across all matching rows in the database, which scales poorly. `exists()` triggers a highly optimized `EXISTS(LIMIT 1)` check directly at the database level.
**Action:** When working with Django QuerySets, always use `.exists()` to check if a QuerySet contains any results. Never use `len(queryset) != 0` or `queryset.count() == 0` for simple true/false checks, as this causes significant memory usage and unnecessary processing at the database level.
