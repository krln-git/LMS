## 2024-05-18 - Avoid using count() == 0 or count() != 0 for existence checks
**Learning:** Using `.count() == 0` or `.count() != 0` on a Django QuerySet for an existence check evaluates a `SELECT COUNT(...)` query. If the check is immediately followed by accessing the elements or returning True/False based on existence, it triggers unnecessary database operations. For simple boolean existence checks, `.exists()` is more performant as it evaluates a `SELECT 1 ... LIMIT 1` query. If the check is followed by accessing the first element via index (e.g., `user[0]`), `.first()` should be used to do both the check and retrieval in one query.
**Action:** Replace `.count() == 0` with `.exists()` when checking boolean existence. Replace it with `.first()` when checking existence and accessing the first item.
