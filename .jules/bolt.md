## 2024-05-24 - [Avoid N+1 queries when iterating enrollments]
**Learning:** `CourseEnrollment.enrollments_for_user(user)` does not prefetch `CourseOverview`. If an iteration loop accesses `enrollment.course_overview` (which is often the case since it's used to get `eligible_for_financial_aid` and `display_name`), it results in N+1 queries.
**Action:** Use `CourseEnrollment.enrollments_for_user_with_overviews_preload(user)` instead. Note that `enrollments_for_user_with_overviews_preload` returns a QuerySet (with `select_related`) in `common/djangoapps/student/models/course_enrollment.py`, so we can chain `.order_by('-created')` directly onto its result. However, some memory instructions say it returns a list, which might be incorrect for the latest codebase. Looking at `common/djangoapps/student/models/course_enrollment.py` line 977, `enrollments_for_user_with_overviews_preload` returns `enrollments_for_user(user).select_related(...)`, which means it is a QuerySet. So it's safe to use `.order_by()`.
